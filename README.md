# iPhone Seken / Scan — Panduan Cek iPhone Second

Aplikasi web panduan inspeksi iPhone second terarah untuk membaca jejak bongkar, kondisi kamera, asal nomor model, keaslian layar, dan baterai sebelum transaksi COD.

🌐 **Demo Langsung (GitHub Pages):**
[https://agusrama79212.github.io/iPhone-seken-scan/](https://agusrama79212.github.io/iPhone-seken-scan/)

---

## ✨ Fitur Utama
1. **Pemeriksaan Berdasarkan Model Spesifik:**
   - Mendukung iPhone SE 2 hingga iPhone 17 Pro Max.
   - Foto inspeksi komponen asli Apple Newsroom / High Resolution (baut pentalobe, kamera fusion, sasis titanium/aluminium, Dynamic Island, Action Button, Camera Control, dll).
   - Spesifikasi akurat per generasi (contoh: Apple ProRAW hanya untuk seri Pro, HEIF Max 48MP untuk seri reguler, USB-C vs Lightning, dsb).

2. **4 Tahap Inspeksi COD Terarah:**
   - **Tahap 1: Fisik & Port** (Baut pentalobe, kaca belakang, sasis, sim tray & LCI indikator air).
   - **Tahap 2: Layar & Touch** (True Tone, kerataan kaca layar, riwayat servis resmi iOS).
   - **Tahap 3: Kamera & Sensor** (Lensa kamera, Face ID TrueDepth / Touch ID, LiDAR, Makro).
   - **Tahap 4: Sistem & IMEI** (Nomor model region PA/A vs internasional, status iCloud, baterai).

3. **Interaktif & Responsif:**
   - Checklist progres inspeksi real-time dengan status indikator.
   - Lightbox modal untuk melihat detail foto komponen dalam resolusi tinggi.
   - Latar belakang animasi wave dinamis dengan transisi logo Apple.
